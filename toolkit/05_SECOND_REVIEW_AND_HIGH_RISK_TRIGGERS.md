# Second Review and High-Risk Trigger Checklist

## Trigger any second review if YES to one or more:
- [ ] Single-source core allegation
- [ ] High hierarchy differential (senior vs junior)
- [ ] Language/interpreter complexity
- [ ] Potential high-consequence action (termination/regulatory reporting)
- [ ] Heavy reliance on credibility vs objective evidence
- [ ] Protected-class/retaliation allegation sensitivity
- [ ] Significant process deviation from standard protocol

## Second reviewer tasks
- [ ] Re-score credibility matrix independently
- [ ] Verify material vs peripheral contradiction calls
- [ ] Re-run disconfirmation checks
- [ ] Verify quote fidelity and evidence linkage
- [ ] Confirm consistency with comparable prior outcomes
- [ ] Confirm legal/process fairness requirements met

## Outcome of second review
- [ ] Agree with initial finding
- [ ] Modify confidence level
- [ ] Modify finding category
- [ ] Return for additional investigative steps
