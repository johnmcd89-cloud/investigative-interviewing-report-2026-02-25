# Toolkit Index

Use these templates together in sequence:

1. `01_CASE_INTAKE_AND_PLAN_TEMPLATE.md` — scope, hypotheses, evidence, interview order.
2. `02_INTERVIEW_RUN_OF_SHOW_AND_QUESTION_BANK.md` — live interview execution aid.
3. `03_CREDIBILITY_MATRIX_TEMPLATE.md` — structured credibility scoring.
4. `04_CONFIDENCE_RUBRIC_AND_DECISION_RULES.md` — normalize finding thresholds.
5. `05_SECOND_REVIEW_AND_HIGH_RISK_TRIGGERS.md` — quality control and escalation.
6. `06_FINDINGS_MEMO_TEMPLATE.md` — final defensible write-up.
7. `07_RETALIATION_MONITORING_PLAN_TEMPLATE.md` — post-case protection and follow-up.

Recommended usage: attach these templates to each case folder and complete them contemporaneously.
